# Портфоліо відеографа та фотографа — інструкція

## Що в папці

| Файл | Навіщо |
|---|---|
| `index.html` | структура сторінки (відкривається у браузері подвійним кліком) |
| `style.css` | дизайн, кольори, адаптив |
| `script.js` | плеєр, лайтбокс, меню, анімації |
| **`content.js`** | **увесь контент — редагуєте тільки цей файл** |
| `media/` | сюди можна класти власні фото та відео |

## Як замінити контент

Відкрийте `content.js` у будь-якому текстовому редакторі (VS Code, TextEdit, Notepad) і замініть заглушки:

- `YOUR_NAME` — ім'я.
- `YOUR_INSTAGRAM_URL` — `https://instagram.com/username` (або просто `@username`).
- `YOUR_EMAIL` — `name@gmail.com`.
- `YOUR_TELEGRAM_URL` — `https://t.me/username` (або `@username`).
- `VIDEO_URL` — посилання на відео.
- `thumbnail` / `src` — посилання на обкладинку чи фото.

Поки заглушка не замінена, елемент **не показується** відвідувачам — на сайті не буде порожніх кнопок чи битих посилань.

Після заміни демо-зображення видаліть у цьому записі `demo: true`.

## Які посилання на відео підходять

- **YouTube** — `https://youtu.be/...`, `https://www.youtube.com/watch?v=...`, `.../shorts/...` (Shorts автоматично відкриваються вертикально).
- **Vimeo** — `https://vimeo.com/123456789` (для приватних — повне посилання з хешем).
- **Google Drive** — `https://drive.google.com/file/d/.../view` (доступ: «Усі, хто має посилання»).
- **MP4-файл** — наприклад `media/reel-1.mp4`, якщо файл лежить у папці `media`. Вертикальні MP4 визначаються автоматично; для інших можна додати `vertical: true`.

Кілька відео в одній категорії — просто додайте ще об'єкти в масив `items`, у плеєрі з'являться кнопки «Попереднє / Наступне».

## Як додати фото

1. Покладіть файл у `media/`, наприклад `media/product-01.jpg`.
2. У `content.js` вкажіть `src: "media/product-01.jpg"` і короткий опис в `alt`.
3. Перші 3–4 фото категорії складають колаж, решта доступні в лайтбоксі (на останній плитці буде «+N»).

Рекомендовано: фото по довшій стороні до 2000 px, у форматі JPG/WebP — сайт вантажитиметься швидко.

## Режим налаштування

Додайте `?setup` в кінець адреси (`index.html?setup`) — побачите пунктирні мітки на порожніх слотах і список того, що ще не заповнено. Звичайні відвідувачі цього не бачать.

## Публікація

- **GitHub Pages**: створіть репозиторій, завантажте всі файли (разом з `media/`), Settings → Pages → Deploy from branch → `main` / root.
- **Netlify**: перетягніть папку на app.netlify.com/drop — отримаєте посилання за хвилину.

Важкі відео (понад ~50 МБ) краще викласти на YouTube/Vimeo, а на сайт вставити посилання.
